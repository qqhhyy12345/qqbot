# QQ 机器人部署说明（SnowLuma + AstrBot）

部署位置：**`D:\qqbot`**
- **SnowLuma 2.1.1**：QQ 协议端，把 QQ 原生会话转成 OneBot v11
- **AstrBot 4.29.1**：机器人框架，接大模型、管人格 / 插件 / 知识库

> 旧目录 `D:\dsh\wkspc1\qqbot` 是历史副本，**已废弃**，不要再从那里启动。原因见文末「完整性标签的坑」。

链路：QQ 小号(<BOT_QQ>) ──注入──> SnowLuma ──反向 WS──> AstrBot ──HTTP──> 火山方舟

```
QQ 客户端  ──hook──>  SnowLuma  ──ws://127.0.0.1:6199/ws──>  AstrBot  ──>  ark.cn-beijing.volces.com
                       WebUI 5099                              WebUI 6185
                       OneBot 3000 / 3001
```

## 一、日常启动

双击 **`D:\qqbot\start-all.bat`**：依次弹出两个窗口（SnowLuma、AstrBot），并自动打开两个面板。

单独启动用 `start-snowluma.bat` / `start-astrbot.bat`。两个窗口必须一直开着，关掉即停服。

顺序无所谓：SnowLuma 会持续探测 `QQ.exe` 并自动注入，先开 QQ 或先开 SnowLuma 都行。

## 四、怎么用

私聊机器人（或群聊里 @ 它 / 前缀 `/`）即可。群里默认需要唤醒，私聊不需要。

想限制谁能用：AstrBot 面板 → 配置 → 平台设置，把 `id_whitelist` 填上 QQ 号，再把 `enable_id_white_list` 打开。

## 六、升级

- **SnowLuma**：下载新版 `win-x64` 包，解压覆盖 `snowluma\`，保留 `snowluma\config\` 和 `snowluma\data\`。
- **AstrBot**：在 `D:\qqbot` 执行

  ```
  set UV_TOOL_DIR=D:\qqbot\_uv_tools
  set UV_TOOL_BIN_DIR=D:\qqbot\_uv_bin
  set UV_CACHE_DIR=D:\qqbot\_uv_cache
  uv tool upgrade astrbot --python 3.12
  ```

## 七、排障

| 现象 | 排查 |
| --- | --- |
| 面板打不开 | 窗口被关了？端口 5099 / 6185 被占用？ |
| QQ 没被注入 | 看日志有没有 `Node integrity: ... process=Medium`。若是 `process=Low`，说明文件带 Low 完整性标签（见文末），必须从 `D:\qqbot` 启动 |
| OneBot 端口 3000/3001 没监听 | 账号没注入成功；账号在线后才会拉起 OneBot |
| AstrBot 里平台断开 | 看 `logs\astrbot.log` 有没有 `适配器已连接`；SnowLuma 侧看 `WS-Client [astrbot] connected` |
| 能收消息但不回复 | 模型问题：面板「服务提供商」→ volcengine-ark → 点测试 |
| 群里不回复 | 需要在群里 @ 机器人或用前缀 `/` |
| SnowLuma 报 QQ 版本不兼容 | native hook 与 QQ 版本绑定；QQ 大版本升级后可能要等 SnowLuma 更新 |

## 八、完整性标签的坑（重要）

DSH 的会话工作区（`D:\dsh\wkspc1`）带 `Low Mandatory Level:(OI)(CI)(NW)` 标签，工作区里的 exe / bat 全部继承它。Windows 会把从这种文件启动的进程降到**低完整性级别**，低完整性进程**无法注入** QQ（Medium 级别），表现为 `/api/processes` 空列表、日志零注入记录。

改标签需要 `SeSecurityPrivilege`（管理员权限），普通账户改不动（试过，67437 个文件全部 Access denied）。所以整套部署被复制到了 `D:\qqbot`（`D:\` 无该标签）。**不要把它搬回 DSH 工作区**，否则注入会重新失效。

## 九、风险提示

- 第三方协议端接 QQ 属非官方用法，账号可能被风控甚至封禁，**务必用小号**。
- 两个面板都只监听 `127.0.0.1`，外网访问不到。
- API Key 明文存在 `astrbot\data\cmd_config.json`，该文件不要外发。
